# Real CIL / CMPDI Document Dataset — Source Pack

This pack contains **12 real public-source document references** selected for the SIH 2026 CMPDI/CIL document-intelligence problem.

Important:
- These are **real public documents**, not synthetic data.
- The pack intentionally does **not** claim to contain confidential CIL internal records.
- Two entries (#11 and #12) are real Coal India Limited documents whose public copies contain scanned handwritten signatures/annotations. They are included for handwriting/signature/scan-quality testing.
- A public web search cannot guarantee that every old CIL/CMPDI archive contains handwritten operational registers. Confidential/internal mine registers should be obtained through an authorized CIL/CMPDI source.
- The original binaries could not be bundled automatically in this runtime because external binary downloads are blocked. The included downloader retrieves the exact public URLs listed in the manifest.
